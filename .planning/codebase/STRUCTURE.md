## Directory Purposes

**icons/**
- Purpose: Extension icons at various sizes
- Contains: `icon16.svg`, `icon48.svg`, `icon128.svg`
- Key files: All required for Chrome extension manifest

**lib/**
- Purpose: Third-party CSS frameworks
- Contains: `pico.min.css` (Pico CSS framework)
- Key files: Single dependency

**mockups/**
- Purpose: UI design experiments and alternatives
- Contains: HTML mockup files for different layouts
- Key files: `mockup-2-dock.html` (implemented design), `HANDOFF-MOCKUP-2.md`

**rightclick/**
- Purpose: Experimental right-click bookmark feature
- Contains: `right-click.html`, `right-click.css`, `right-click.js`
- Status: Experimental/incomplete

## Key File Locations

**Entry Points:**
- `popup.html` + `popup.js` - Browser action popup
- `newtab.html` + `newtab.js` - New tab override
- `manage.html` + `app.js` + `ui.js` - Full management UI

**Configuration:**
- `manifest.json` - Chrome extension manifest (permissions, entry points)

**Core Logic:**
- `storage.js` - All data operations (CRUD for categories/links)
- `ui.js` - DOM rendering for management page
- `newtab.js` - Dock UI rendering

**Utilities:**
- `context-menu.js` - Reusable context menu component
- `import-export.js` - Backup/restore functionality

**Styling:**
- `styles.css` - Custom styles for management page
- `lib/pico.min.css` - Base CSS framework
- Inline styles in `newtab.html` - Dock-specific styling

**Documentation:**
- `README.md` - User-facing documentation
- `HANDOFF.md` - Developer handoff notes
- `HANDOFF-DOCK-IMPLEMENTATION.md` - Dock implementation notes

## Naming Conventions

**Files:**
- kebab-case for multi-word files (`import-export.js`, `context-menu.js`)
- Single word for main modules (`storage.js`, `popup.js`, `newtab.js`)
- UPPERCASE.md for important docs (`README.md`, `HANDOFF.md`)

**Directories:**
- lowercase for all directories (`icons/`, `lib/`, `mockups/`)

**Special Patterns:**
- `*.html` paired with `*.js` for each entry point
- No barrel files (each JS file loaded via script tag)

## Where to Add New Code

**New Feature:**
- Primary code: Root directory (new `.js` file)
- UI changes: Modify corresponding `.html` file
- Styles: Add to `styles.css` or inline in HTML

**New UI Component:**
- Implementation: Create new `.js` file in root
- Styles: Add section to `styles.css`
- Integration: Add script tag to relevant HTML files

**New Settings Option:**
- Data schema: Update `DEFAULT_DATA` in `storage.js`
- UI: Add to settings section in `newtab.html`
- Logic: Add handler in `newtab.js` `attachEventListeners()`

**Utilities:**
- Shared helpers: Add to existing utility files or create new
- No utilities directory (flat structure)
