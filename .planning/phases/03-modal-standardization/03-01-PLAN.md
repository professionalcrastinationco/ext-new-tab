Output: Unified modal system across newtab.html using native dialog API.
</objective>

**Codebase constraints:**
- Use native `<dialog>` element with `.showModal()` and `.close()` API
- Follow existing modal patterns from manage.html (Pico CSS article wrapper)
- Maintain dark slate theme with cyan accents
- No external dependencies

**Current state audit:**
- manage.html: All 3 modals already use native `<dialog>` (link, category, confirm)
- newtab.html: 2 modals use native `<dialog>` (link, category)
- newtab.html: Settings modal uses div-based `.settings-modal` with CSS `.show` toggle
- newtab.js: Uses native `confirm()` browser dialogs (lines 183, 264)

**Pattern to follow (from manage.html):**
```html
<dialog id="confirm-modal">
  <article>
    <header><h3>Confirm Delete</h3></header>
    <p id="confirm-message"></p>
    <footer>
      <button type="button" class="secondary" id="cancel-confirm-btn">Cancel</button>
      <button type="button" class="contrast" id="confirm-delete-btn">Delete</button>
    </footer>
  </article>
</dialog>
```

<task type="auto">
  <name>Task 1: Convert settings modal to native dialog</name>
  <files>newtab.html, newtab.css, newtab.js</files>
  <action>
1. In newtab.html:
   - Replace `<div class="settings-modal" id="settingsModal">` with `<dialog id="settings-modal">`
   - Wrap content in `<article>` element for Pico CSS styling
   - Update close button to use standard pattern from other modals
   - Keep all settings content (appearance, bookmarks, categories sections)

2. In newtab.css:
   - Remove `.settings-modal` and `.settings-modal.show` display toggle rules
   - Keep `.settings-content`, `.settings-header`, `.settings-section`, `.setting-item` styles but adjust for dialog context
   - Add `dialog#settings-modal` styles for backdrop and sizing
   - Ensure dark theme consistency (slate background, cyan accents)

3. In newtab.js:
   - Update settings button click to use `document.getElementById('settings-modal').showModal()`
   - Update close button to use `.close()` instead of class toggle
   - Remove `settingsModal.classList.add/remove('show')` calls
   - Add click-outside-to-close behavior using dialog backdrop click pattern
  </action>

   - Press Escape - dialog should close
   - Click backdrop - dialog should close
   - Settings content and functionality unchanged
