  <action>
Chrome extensions require PNG icons in manifest, not SVG.

1. Create PNG versions of the bookmark icon at 16x16, 48x48, and 128x128 pixels:
   - Use a simple bookmark shape (Phosphor bookmark-simple icon works)
   - Export as PNG with transparent background
   - Save to icons/icon16.png, icons/icon48.png, icons/icon128.png

2. Update manifest.json to reference PNG files instead of SVG:
   ```json
   "icons": {
     "16": "icons/icon16.png",
     "48": "icons/icon48.png",
     "128": "icons/icon128.png"
   },
   "action": {
     "default_icon": {
       "16": "icons/icon16.png",
       "48": "icons/icon48.png",
       "128": "icons/icon128.png"
     },
     ...
   }
   ```

3. Keep SVG files as source reference (don't delete)

For PNG generation, create a simple Node.js script using sharp or canvas, OR manually export from a design tool. The icon should be recognizable as a bookmark at small sizes.

NOTE: If programmatic PNG generation is complex, create simple colored bookmark shapes using basic drawing - a filled bookmark silhouette works fine.
