**Issue:** Category cards (bookmark cards) on newtab page have a solid dark background that doesn't match the polished glassmorphism styling of the right-click context menu.

**Target styling (from context menu in newtab.css lines 640-670):**
```css
--menu-bg: linear-gradient(45deg, rgba(10, 20, 28, 0.2) 0%, rgba(10, 20, 28, 0.7) 100%);
backdrop-filter: blur(5px);
border-radius: 8px;
box-shadow: 0 0 0 1px rgba(255, 255, 255, 0.08),
    0 2px 2px rgb(0 0 0 / 3%),
    0 4px 4px rgb(0 0 0 / 4%),
    0 10px 8px rgb(0 0 0 / 5%),
    0 15px 15px rgb(0 0 0 / 6%),
    0 30px 30px rgb(0 0 0 / 7%),
    0 70px 65px rgb(0 0 0 / 9%);
```

**Current bookmark card styling (newtab.css lines 280-290):**
```css
background-color: rgba(30, 41, 59, 0.95);
backdrop-filter: blur(20px);
border: 1px solid rgba(148, 163, 184, 0.2);
border-radius: 12px;
box-shadow: 0 20px 50px rgba(0, 0, 0, 0.5);
```

**Key differences to fix:**
1. Background: solid rgba → linear gradient (more glass-like)
2. Shadow: single shadow → layered shadow (matches context menu)
3. Border: explicit border → inner glow via box-shadow (cleaner)
