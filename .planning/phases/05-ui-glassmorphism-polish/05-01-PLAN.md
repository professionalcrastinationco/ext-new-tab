  <action>
1. Add tokens.css import BEFORE styles.css in head:
   `<link rel="stylesheet" href="tokens.css">`

2. Add inline style to override Pico's background:
   In the existing `<style>` tag or add new one:
   ```css
   :root {
     --background-color: var(--color-base);
     --card-background-color: var(--glass-bg-light);
     --muted-border-color: var(--color-border);
   }
   body {
     background-color: var(--color-base);
   }
   ```

This maps Pico CSS variables to our design tokens, making the transition seamless.
  </action>
