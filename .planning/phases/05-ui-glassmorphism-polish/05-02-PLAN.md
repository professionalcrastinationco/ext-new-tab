<task type="auto">
  <name>Task 3: Apply glass styling to form inputs</name>
  <files>styles.css</files>
  <action>
Add glass input styles that will apply to manage.html forms (category/link modals already use Pico, but we can enhance):

```css
/* Glass input override for Pico */
input[type="text"],
input[type="url"],
select {
  background: rgba(51, 65, 85, 0.8) !important;
  border: 1px solid rgba(148, 163, 184, 0.3) !important;
  border-radius: var(--radius-md) !important;
  color: var(--color-text) !important;
  padding: var(--space-3) !important;
  font-size: var(--font-size-base) !important;
  font-family: var(--font-family) !important;
  transition: all var(--transition-fast) !important;
}

input[type="text"]:focus,
input[type="url"]:focus,
select:focus {
  outline: none !important;
  border-color: rgba(6, 182, 212, 0.5) !important;
  box-shadow: 0 0 0 3px rgba(6, 182, 212, 0.1) !important;
}

input::placeholder {
  color: var(--color-text-subtle) !important;
}
```

Note: Using !important to override Pico CSS defaults. This is acceptable for a design system override layer.
