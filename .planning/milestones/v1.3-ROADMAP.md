1. Quick access icon strip below search bar with glassmorphism styling

3. User-editable quick links with add/edit/delete via context menu and modal

- Combined brand + category icons in picker for maximum flexibility
- Context menu pattern matches existing bookmark/category context menus
- Used SVG scale transform for official logos (keeps paths intact for updates)
